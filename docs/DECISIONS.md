- Exclude `casual`, `registered`: they sum to `cnt` exactly. Leaky model R^2 1.000 -> honest ridge 0.583.
- Exclude `cnt_2d_bfr`: a shipped 2-day lag we cannot test the alignment of. Build our own lags instead.
- Exclude `instant`, `yr`, `days_since_2011`: time indexes let a tree predict a flat constant past 2011 and a linear model extrapolate a trend we have no grounds for.
- Split 2011 / H1 2012 / H2 2012 by date. Test set touched once, after all feature work.
- Report mean and persistence baselines with every score. Persistence (test R^2 0.510, MAE 840) is within 0.07 R^2 of ridge and beats it on MAE; that caveat goes in the report.
- 2026-11-25: Added `cnt_roll_3` (3-day rolling mean of prior ride counts; when forecasting Jan 12, the Jan 9-11 ride counts are already known). Validation R^2 changed ridge 0.6475 -> 0.6439 (delta -0.0036) and hgb 0.2185 -> 0.1983 (delta -0.0202); both fell short of the +0.01 guideline. We kept cnt_roll_3 in the default training pipeline to reproduce the 15-feature experiment. Based on the validation results, we recommend using the original 14 features for forecasting.

- 2026-11-25: Exercise 4 validation freeze (AI-assisted): compare only additive residuals and log ratios relative to the verified prior-seven-day mean, with the same 15 inputs, 2011 training split, Ridge alpha=1 and HGB max_iter=300/random_state=0. Select log_ratio for HGB using validation R^2 0.7488 and MAE 687.6 (raw HGB 0.1983/1311.6; residual HGB 0.7209/722.4). Also freeze the strongest linear control, residual Ridge (0.6545/822.0), against original Ridge (0.6439/836.5). This is defensible for rolling one-day-ahead prediction because the inverse uses only observed t-1..t-7 counts, while relative-error stationarity and inverse-log bias remain assumptions. Retain the transformation behind an experimental flag; canonical metrics remain untransformed. Freeze code/data hashes and one output path before one new held-out comparison. Earlier exercises/self-audit had already reproduced the original pipeline test metrics; no transformed test metric was used in this choice.
- 2026-11-25: Exercise 5: under an explicitly assumed loss proportional to absolute daily error, retain persistence rather than deploy the current untransformed Ridge. Existing results on the same 184 test days show Ridge R^2 0.5800 versus 0.5099 (+0.0701), but MAE 946.2 versus 840.1 (+106.1 rides/day, +12.6%). The R^2 difference implies approximately 14.3% lower MSE on those days, so a decision that heavily penalizes large misses would require a separately specified cost objective. Both beat the mean baseline (R^2 -2.1441, MAE 2847.7), which does not establish Ridge's advantage over persistence. Drafted the argument from existing metrics; no model, data, score, or test evaluation was changed.
